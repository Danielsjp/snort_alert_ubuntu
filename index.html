Instalación de Snort en Ubuntu y detección de escaneos Nmap

Configura un sistema de detección de intrusiones, crea una regla personalizada y detecta actividad de reconocimiento de red desde una segunda máquina.

⏱ 75-90 minutos 📚 Nivel intermedio 🐧 Ubuntu + Kali Linux 🛡 Snort IDS
OBJETIVOS

1. Objetivos de la práctica

Al finalizar esta actividad serás capaz de:

✓ Instalar Snort
En Ubuntu mediante APT.
✓ Configurar HOME_NET
Definir la red protegida.
✓ Crear reglas IDS
Detectar patrones TCP SYN.
✓ Utilizar Nmap
Generar tráfico de reconocimiento.
✓ Analizar alertas
Interpretar los eventos detectados.
TOPOLOGÍA

2. Escenario del laboratorio

Vamos a utilizar dos máquinas virtuales conectadas a la misma red interna de VirtualBox o VMware.

🛡 Máquina 1 · Sensor IDS

Ubuntu + Snort
192.168.56.10
Función: monitorizar el tráfico dirigido a Ubuntu.

Interfaz: enp0s3 (ejemplo)

⚡ Máquina 2 · Escáner

Kali Linux + Nmap
192.168.56.20
Función: realizar un escaneo de puertos contra Ubuntu.
Importante: las direcciones IP son ejemplos. Ambas máquinas deben estar conectadas a la misma red y debes adaptar las direcciones a tu laboratorio.
INSTALACIÓN

3. Instalar Snort en Ubuntu

1

Actualizar repositorios

Abre una terminal en Ubuntu:

sudo apt update
sudo apt upgrade -y
2

Instalar Snort

sudo apt install snort -y

Si el asistente solicita la red que debe proteger, introduce:

192.168.56.0/24

Si no aparece el asistente, configuraremos HOME_NET manualmente.

3

Comprobar la instalación

snort -V

Comprueba la versión instalada. Esta práctica utiliza la sintaxis de Snort 2.

Compatibilidad: comprueba que tienes Snort 2.x. Las rutas y comandos de esta práctica corresponden a Snort 2. Snort 3 utiliza una configuración diferente.
CONFIGURACIÓN

4. Identificar la interfaz de red

Necesitamos identificar la interfaz que conecta Ubuntu con la red interna.

ip -br address
ip route

Busca una interfaz con una dirección similar a:

enp0s3    UP    192.168.56.10/24
Anota estos datos:
  • IP de Ubuntu: __________________
  • IP de Kali: __________________
  • Interfaz de Ubuntu: __________________
  • Red protegida: __________________
HOME_NET

5. Configurar la red protegida

1

Abrir el archivo de configuración

sudo nano /etc/snort/snort.conf
2

Modificar HOME_NET

Busca la variable:

ipvar HOME_NET any

Sustitúyela por:

ipvar HOME_NET 192.168.56.0/24
3

Comprobar la carga de reglas locales

Busca la siguiente directiva:

include $RULE_PATH/local.rules

Si está comentada, descoméntala.

Guarda con Ctrl+O y sal con Ctrl+X.

REGLAS IDS

6. Crear una regla para detectar Nmap

Vamos a crear una regla personalizada que genere una alerta cuando detecte una frecuencia elevada de paquetes TCP SYN dirigidos a nuestra red protegida.

Paso 1. Abrir el fichero local.rules

sudo nano /etc/snort/rules/local.rules

Paso 2. Introducir la regla completa

alert tcp any any -> $HOME_NET any (msg:"ALERTA - POSIBLE ESCANEO NMAP SYN"; flags:S; detection_filter:track by_src, count 10, seconds 5; sid:1000001; rev:1;)
La regla se copia en una única línea. Aunque visualmente se ajuste a varias líneas en pantallas pequeñas, su sintaxis permanece intacta.

Paso 3. Interpretación de la regla

ElementoSignificado
alert tcpGenera una alerta para tráfico TCP.
any anyCualquier IP y puerto de origen.
$HOME_NET anyCualquier puerto de la red protegida.
flags:SBusca paquetes TCP con el indicador SYN activado.
detection_filterEstablece un umbral de frecuencia por IP de origen.
count 10Umbral de 10 coincidencias.
seconds 5Intervalo temporal de 5 segundos.
sid:1000001Identificador único de nuestra regla.
¿Qué estamos detectando? Nmap con la opción -sS genera paquetes TCP SYN para comprobar el estado de los puertos. La regla detecta un patrón de tráfico, no identifica exclusivamente el programa Nmap.
VALIDACIÓN

7. Validar la configuración de Snort

Antes de arrancar el IDS, comprobamos que la configuración y las reglas son correctas.

sudo snort -T -c /etc/snort/snort.conf
Resultado esperado: 
Snort successfully validated the configuration!
Si aparecen errores, revisa HOME_NET, local.rules y la sintaxis de la regla.
MODO IDS

8. Activar Snort en modo detección

Ejecuta Snort indicando la interfaz de red correcta:

sudo snort -A console -q \
-c /etc/snort/snort.conf \
-i enp0s3

Sustituye enp0s3 por la interfaz real de tu Ubuntu.

Importante: deja esta terminal abierta. Snort estará escuchando el tráfico y mostrará las alertas cuando se cumplan las condiciones de las reglas.
SIMULACIÓN

9. Lanzar un escaneo Nmap desde Kali

Cambiamos ahora a la segunda máquina virtual: Kali Linux.

Paso 1. Comprobar conectividad

ping -c 4 192.168.56.10

Paso 2. Ejecutar el escaneo TCP SYN

sudo nmap -sS -T4 -p 1-1000 192.168.56.10
OpciónDescripción
-sSEscaneo TCP SYN.
-T4Temporización rápida.
-p 1-1000Escanea los puertos 1 al 1000.
IP destinoMáquina Ubuntu.

Resultado esperado en Ubuntu

[**] [1:1000001:1]
ALERTA - POSIBLE ESCANEO NMAP SYN
{TCP} 192.168.56.20:XXXXX -> 192.168.56.10:80
Objetivo conseguido: Snort ha detectado el patrón de paquetes SYN procedentes de Kali y ha generado una alerta.

El puerto y el formato exacto pueden variar.

REGISTROS

10. Consultar las alertas almacenadas

Opcionalmente podemos guardar las alertas en un fichero.

Detén Snort con Ctrl+C y ejecuta:

sudo snort -A fast \
-c /etc/snort/snort.conf \
-i enp0s3 \
-l /var/log/snort

Desde Kali vuelve a lanzar el escaneo.

Después consulta las alertas:

sudo cat /var/log/snort/alert
